# Changelog

## 1.0.0 — Integrated workflow

- Added `h2md-workflow` commands: `plan`, `run`, `analyze`, `dashboard`.
- Added JSON-driven multi-system campaigns for reproducible size or thermodynamic-state sweeps.
- Added interactive, offline campaign comparison dashboard; exports CSV, JSON, and Markdown.
- Preserved all previous molecular analysis and 3D visualization commands.
- Added Windows upgrade instructions, campaign example, provenance notes, and automated workflow tests.
- No new force-field calibration or experimental diffusion validation is claimed.

## 0.5.0 — Quantitative analysis

- Multiple independent LAMMPS replicas; density EOS benchmark; molecular self-diffusion with 95% confidence intervals.
- Improved SHAKE/dump precision diagnostics and high-precision trajectory output.

## 0.4.0 — Paper-based H₂ model

- Published two-site Lennard–Jones site parameters from Adam et al., DOI:10.1016/j.ijhydene.2024.06.319.
- Documented the separate rigid-bond approximation.

## 0.1–0.3 — Educational foundations

- Single-site and two-site simulation demos, molecular COM analysis, RDF, and interactive 3D visualization.
